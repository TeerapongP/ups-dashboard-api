# UPS Dashboard API

## Overview

UPS Dashboard API is a FastAPI-based backend service designed to monitor and manage UPS systems efficiently.  
It provides RESTful endpoints under the `/api` prefix.

---

## Features

- FastAPI framework for high performance and automatic docs  
- Clean, modular project structure  
- Swagger UI and ReDoc API documentation  
- Docker-ready for easy deployment

---
